# NordFlow Tasks — план реализации

Источник требований: `info/tz.txt`.

## Выбранный стек (Этап 0)
- **Web:** Next.js (App Router) + TypeScript + Tailwind CSS (`web/`)
- **Данные:** **SQLite + Prisma** на старте (быстрый локальный MVP), с возможной миграцией на PostgreSQL позже
- **Auth:** сессии (cookie) + RBAC (Этап 2)
- **UI:** shadcn/ui, @dnd-kit для Kanban, тема light/dark

### Этап 1 — Простой MVP (без полноценной авторизации)
- Проекты: список, создание/редактирование, страница проекта
- Задачи: создание/редактирование (обязательные поля), карточка/страница задачи
- Kanban (Бэклог→Выполнено) + список, смена статуса (DnD/упрощённо на мобайле)
- Базовые фильтры/поиск по задачам, персистентность в БД
- Временная заглушка «текущий пользователь»

### Этап 2 — Авторизация и разграничение доступа
- Логин/выход, сохранение сессии, ошибки входа, show/hide password
- Управление пользователями (админ), роли
- RBAC: видимость и действия по ролям, без самостоятельной регистрации

### Этап 3 — Основные рабочие разделы
- Главная, «Мои задачи» (фильтры, список/доска, просрочка)
- Вкладки проекта (Доска/Список/Участники/Информация)
- Полная карточка задачи (NDF-xxx, теги, дедлайны, приоритеты, вложения)
- Комментарии, история изменений

### Этап 4 — Команда, профиль, уведомления, поиск
- Раздел «Команда» и загрузка сотрудников
- Профиль, смена пароля/темы (ограничения по email/роли)
- In-app уведомления (события по ТЗ)
- Глобальный поиск с группировкой

### Этап 5 — Полировка и приёмка
- Полная адаптивность (ПК/планшет/смартфон) по ТЗ
- Демо-данные: 8 пользователей, 3 проекта, ≥25 задач, комментарии/история
- Проверка сценариев 1–4 и критериев приёмки п.26

## Решения/риски
- Вложения/аватары: локальное хранилище в MVP, абстракция под S3 позже
- «Приближается дедлайн»: вычисление при запросе + периодическая проверка (уточнить на Этапе 4)
- История изменений: ключевые события (статус, исполнитель, срок, приоритет)
